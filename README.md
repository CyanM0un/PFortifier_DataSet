# PFortifier_Dat
This is the data set for the paper: [PFortifier](https://github.com/HACHp1/PFortifier): Mitigating PHP Object Injection through Automatic Patch Generation. Please cite the above paper if you use our data set.

For known gadget chains, please refer to [phpggc](https://github.com/ambionics/phpggc/tree/16a82e0c9538c2e779557461eb1fe4031a7b00f3). For new gadget chains discovered by PFortifier, please see [new_chains_call_stack](https://github.com/CyanM0un/PFortifier_DataSet/new_chains_call_stack.md) for more details. We also submit all the new chains to the [phpggc](https://github.com/ambionics/phpggc/pulls?q=CyanM0un).

Feel free to use PFortifier to detect and patch PHP gadget chains, and we sincerely welcome PRs to expand the dataset.
